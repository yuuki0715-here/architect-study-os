# 一級建築士 Study OS PWA v0.4（公開用アプリ本体）

v0.3からの変更点:
- 「進捗リセット」をホーム画面から設定画面へ移動
- 「端末の問題データを削除」も設定画面へ移動
- ホーム画面に「全体進捗（PWA記録）」を追加
- 既存のv0.3進捗を保持するため localStorage の保存キーは変更していません

## 全体進捗について
全1,250問を分母として、このPWAで初回回答したユニーク問題数を表示します。
ChatGPT側で過去に実施した学習履歴は自動では含まれません。

問題データはWeb公開せず、個人学習用JSONを端末のIndexedDBへ読み込む方式を継続します。
