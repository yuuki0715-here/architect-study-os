# 一級建築士 Study OS PWA v0.5.2

個人学習用の軽量PWAです。

## v0.5.2 の変更点
- 画面上部に正確なパッチバージョン `v0.5.2` を常時表示
- 設定画面に「アプリ情報」を追加
- Version / Build日 / 問題データ形式を確認可能
- キャッシュ名と静的ファイルのクエリを `v0.5.2` に統一

## v0.5 / v0.5.1 から継続する機能
- 複数の「科目 ＞ 分野」を同じPWAに保存
- 追加JSONは既存データへマージ（同一IDは重複しない）
- 問題本文はGitHub Pagesには置かず端末内IndexedDBに保存
- `imageDataUrl` による図問題対応
- PWA進捗はlocalStorageに保存

`STORAGE_KEY` は既存版と同じため、v0.5.1から更新しても端末内の学習履歴を引き継ぎます。
