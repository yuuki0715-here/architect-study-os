# 一級建築士 Study OS PWA v0.6.0

## v0.6.0 — 計画200問ダッシュボード版

- 学科Ⅰ「計画」10年分200問の全体進捗をホーム画面に表示
- 端末に読み込まれている計画問題数を `200問中何問` で表示
- 計画の分野一覧を、本試験の平均出題位置が早い順に表示
- 各分野の進捗を `回答済み / 問題数` とミニ進捗バーで表示
- 分野一覧から1タップで分野切替
- 現在分野を完了すると、次の未完了分野へ移動可能
- 既存のIndexedDB問題データ・localStorage学習履歴はそのまま引継ぎ
- 5科目全体の1,250問進捗表示も継続

## 問題データ
問題本文はGitHub Pagesには置かず、個人用JSONから端末内IndexedDBへ保存します。

## 互換性
- unit JSON v1 / v1.1 を継続利用
- STORAGE_KEY / IndexedDB名は変更しない
