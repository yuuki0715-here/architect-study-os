# 一級建築士 Study OS PWA v0.5.3

個人学習用の軽量PWAです。

## v0.5.3 の変更点
- JAEIC公式で複数の正答肢を認める問題に対応
- 個人用JSONの任意フィールド `acceptedAnswers`（例: `[1, 4]`）を追加
- 従来の単一正答 `answer` のJSONはそのまま利用可能
- 正答が複数の場合は、どちらを選んでも正解として採点し、正答肢をすべて表示
- 画面上部・設定画面・キャッシュ名を `v0.5.3` に統一

## 継続する機能
- 複数の「科目 ＞ 分野」を同じPWAに保存
- 追加JSONは既存データへマージ（同一IDは重複しない）
- 問題本文はGitHub Pagesには置かず端末内IndexedDBに保存
- `imageDataUrl` による図問題対応
- PWA進捗はlocalStorageに保存

`STORAGE_KEY` は既存版と同じため、更新しても端末内の学習履歴を引き継ぎます。
